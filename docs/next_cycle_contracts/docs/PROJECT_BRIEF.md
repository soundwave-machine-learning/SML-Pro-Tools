# Project brief

Build SML Studio into an easy, responsive and dependable application for recording, editing, mixing and mastering songs. Preserve the existing repository and completed work as the engineering floor. Beatmaking, instrument sequencing and a new engine rewrite are outside this cycle.

## Product priorities
1. No known take loss, session corruption or misleading recovery promises.
2. Correct sample placement, stable low-latency monitoring, accurate routing and compensation.
3. Fast, familiar recording and vocal editing with clear feedback and undo.
4. Professional mixing with personal plugins, shared Console/Visual views and easy buses.
5. Reliable personal-plugin hosting and evidence-backed integration of separately developed SML plugins.
6. Grounded assistance, phone control and reliable mastering/export.

Speed is measured under recording load, not inferred from an empty-window animation. Sound quality is measured and auditioned at matched level. A feature is complete only when its UI, command, engine behavior, persistence, undo where meaningful, documentation and evidence agree.
